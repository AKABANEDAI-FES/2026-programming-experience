# 当日のスタッフマニュアル

プログラミング体験会の当番（システム部）向けのマニュアルです。
開発に関わっていなくても、これを見れば案内と困ったときの対応ができるようにまとめています。

【】の部分は当日までに決めて書き込みます。

## 1. 体験の流れ

参加者は次の順番で進みます。画面の上に「① かく ▶ ② うごかす ▶ ③ うみへ」と、今どこにいるかが出ます。

1. **ホーム**：「じゆうに おえかき」か「イニャーの ぬりえ」を選ぶ
2. **① かく**：マウスで絵をかいて「つぎへ」を押す
3. **② うごかす**：ブロックをならべて動きやセリフを決め、「うみに はなす」を押す
4. **③ うみへ**：絵が上へ泳いでいく。5 秒でホームに戻る
5. **大画面**：かいた絵が上から沈んできて、ブロックのとおりに泳ぐ

- 体験時間の目安は 1 人【◯分】です
- 制作 PC は【8】台です。タッチ操作はできないので、マウスを使ってもらいます

## 3. 画面ごとのポイント

### ホーム

- 「じゆうに おえかき」：白い紙に自由にかく
- 「イニャーの ぬりえ」：イニャーの下絵（ゴーグル・シュノーケル）に色をぬる
- かく画面の上でも、あとから切り替えられます。切り替えると、かいた絵は消えます（確認が出ます）

### ① かく

- 右のパネルで道具を選びます
  - **ペン**：線をかく
  - **けしゴム**：消す
  - **ぬりつぶし**：線でかこんだところを塗る。かこまれていないところは塗れず、「ここは ぬれないよ」と出ます
- 色は 14 色から選べます。「じぶんで えらぶ」で好きな色も作れます（作った色は 5 色まで下に並びます）
- 白っぽい色は大画面で見えなくなるので使えません。選ぶと「しろっぽい いろは つかえないよ」と出ます
- 線の太さは 4 段階です
- 「ひとつ もどす」で 1 つ前に戻せます。「ぜんぶ けす」で全部消せます（確認が出ます）
- 何もかかずに「つぎへ」を押すと「まだ なにも かいてないよ」と出て、先へ進めません
- **「つぎへ」で「これで いい！」を押すと、もう絵は直せません。** 押す前に声をかけてください

#### ぬりえの絵について

イニャーのぬりえは、デザイン部とイニャーの権利を持っている人に確認し、ふつうのぬりえとして楽しむぶんには問題ないと言われています。

- どんな色でぬっても大丈夫です。全身ピンク、色がはみ出している、なども止めません
- 顔をうんちに描きかえるなど、人に見せられない絵になっていたら、「つぎへ」を押す前にやさしく声をかけて直してもらいます（「ぜんぶ けす」や「さいしょから」を使います）
- 大画面に出てしまったあとに気づいたら、担当者に連絡してください

### ② うごかす

- 左の「きみの なかま」に、かいた絵が出ます。ブロックを変えると、その場で動きが見られます
- ブロックの一覧から、右の広いところへドラッグして置きます
- ブロックは上下にくっつけると、上から順に動きます。離して置いたブロックも、上にあるものから順に動きます
- 消すときは、ブロックを右下のゴミ箱へドラッグします（ブロックを選んで Delete キーでも消せます）
- ブロックの種類
  - **うごく**：ジャンプする・くるっとまわる・はやく およぐ・ふくらむ・ぶるぶる ふるえる
  - **いう**：セリフを選ぶ。「じぶんで かく…」を選ぶと、25 文字まで自分で打てます
  - **くりかえす**：中に入れたブロックを 2〜5 回くりかえす
  - **もし ◯◯ なら**：「なかまが ちかくに いる」「はしに いる」「くじが あたる（◯かいに ◯かい）」のときだけ、中のブロックを動かす。合わなかったときに動くブロックも入れられます
- ▼ を押すと、動きやセリフ、回数、条件を選べます
- ブロックは **10 個まで** 置けます（くりかえしや「もし」の中のブロックも数えます）。上の「つかった ブロック ◯ / 10」で数がわかり、いっぱいになると「もう おけないよ」と出ます
- くりかえしや「もし」の中に、さらにくりかえしや「もし」を入れられるのは 1 段までです
- 「うみに はなす」→「はなす！」で大画面に送ります。**送ったあとは直せません**

### ③ うみへ

- 「うみに はなしたよ！ おおきな がめんを みてね」と出て、絵が上へ泳いでいきます
- 大画面のほうを見るよう案内してください
- 5 秒たつと自動でホームに戻るので、次の人に交代します

### 大画面

- 送られた絵は、上から沈んできて、ブロックのとおりに泳ぎます
- 一度に泳げるのは 30 匹までです。それを超えると、古いものから画面の外へ泳いで出ていきます
- 誰もいないときは「いきものが やってくるのを まっています」と出ます

## 4. 混雑しているとき

- 待っている人には、大画面を見ながら待ってもらいます
- 時間がかかっている人には「そろそろ うみに はなそうか」と声をかけます
- 【ほかに決めること：整理券、1 人あたりの時間を短くする、など】

## 5. よくある質問

| 質問                     | 答え                                                                                                              |
| :----------------------- | :---------------------------------------------------------------------------------------------------------------- |
| 描き直したい             | 「つぎへ」の前なら「ひとつ もどす」「ぜんぶ けす」で直せます。そのあとなら「さいしょから」で最初からやり直します  |
| 前の画面に戻りたい       | 戻れません。どうしても直したいときは、左上の「さいしょから」を押します。かいた絵もブロックも消えます              |
| 自分の絵はどこ？         | 送ってすぐ、大画面の上から沈んできます。30 匹を超えると古い順に出ていくので、混んでいるときは早めに見てもらいます |
| 絵を持って帰れる？       | 持って帰れません                                                                                                  |
| もう一回やりたい         | 【並び直してもらう／空いていればそのまま、など】                                                                  |
| 「もし」がうまく動かない | 「なかまが ちかくに いる」は近くにほかの絵がいるとき、「はしに いる」は画面の左右のはしにいるときだけ動きます     |

## 6. 困ったとき

### 当番で対応できること

| 起きたこと                                                    | 対応                                                                     |
| :------------------------------------------------------------ | :----------------------------------------------------------------------- |
| 「まだ おくって いるよ」と出た                                | 少し待ってから「もういちど はなす」を押してもらう                        |
| 「うまく おくれなかったよ」「うまく おくれたか わからないよ」 | 「もういちど はなす」を押してもらう。同じ絵が 2 匹になることはありません |
| ぬりつぶしで「ここは ぬれないよ」と出た                       | 線のすき間をふさいでから、もう一度ぬってもらう                           |
| 参加者が途中でいなくなった                                    | 左上の「さいしょから」→「やりなおす」でホームに戻す                      |
| 大画面に「サーバーとの接続が切れました。再接続しています…」   | 自動でつながり直すので、しばらく待つ                                     |

### 担当者を呼ぶとき

放流用のトークンや Cloudflare を扱えるのは担当者だけです。次のときは、自分で直そうとせずに担当者を呼んでください。

- 「この パソコンは じゅんび ちゅうだよ」と出た（その PC に放流用のトークンが設定されていない）
- 「もういちど はなす」を何回押しても送れない
- 大画面の「再接続しています…」が 1 分以上消えない
- 送れたのに、大画面に絵が出てこない
- 人に見せられない絵が大画面に出てしまった
- 画面が動かない、真っ白になった、知らない画面が出た
- そのほか、わからないこと

**PC を再起動したり、ブラウザを閉じたりしないでください。** 放流の設定がやり直しになることがあります。
