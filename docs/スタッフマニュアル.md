# 当日のスタッフマニュアル

プログラミング体験会の当番（システム部）向けのマニュアルです。開発に関わっていなくても、案内と困ったときの対応ができるようにまとめています。【】の部分は当日までに決めて書き込みます。

## 1. 当番の役割

| 役割   | 人数 | すること                                                             |
| :----- | :--- | :------------------------------------------------------------------- |
| 受付   | 2    | 来た人を空いている PC へ案内する。混雑しているときは待つ列を整理する |
| 見回り | 3    | PC のまわりを回って声をかけ、当番で対応できるトラブルに対応する      |
| 保守   | 1    | 受付や見回りでは直せないトラブルに対応する                           |

## 2. 体験の流れ

- 体験時間の目安は 1 人 10 分（① かく 5 分、② うごかす 5 分）、制作 PC は 8 台です。タッチ操作はできないので、マウスを使ってもらいます
- 画面の上に「① かく ▶ ② うごかす ▶ ③ うみへ」と、今どこにいるかが出ます

1. **ホーム**：「じゆうに おえかき」か「イニャーの ぬりえ」を選ぶ
2. **① かく**：マウスで絵をかいて「つぎへ」を押す
3. **② うごかす**：ブロックで動きやセリフを決めて「うみに はなす」を押す
4. **③ うみへ**：5 秒で自動でホームに戻るので、次の人に交代する
5. **大画面**：かいた絵が上から沈んできて、ブロックのとおりに泳ぐ。来てから 10 秒ほどは絵のまわりが白く光るので、自分の絵を見つけやすい。15 匹を超えると古いものから出ていく

**「つぎへ」と「うみに はなす」を押したあとは、前に戻って直せません。** 押す前に声をかけてください。

## 3. 声かけの例

| 場面                | 声かけ                                                                                                          |
| :------------------ | :-------------------------------------------------------------------------------------------------------------- |
| 席についたとき      | 「海の なかまを かいて、ブロックで うごかしてみよう！ さいごに あの 大きな 画面の 海に はなせるよ」             |
| ホーム              | 「じぶんで かく？ イニャーの ぬりえに する？」                                                                  |
| ① かく              | 「あたまを みぎに むけて かいてね。できたら『つぎへ』を おしてね」                                              |
| 「つぎへ」の前      | 「つぎに すすむと、もう えは なおせないよ。だいじょうぶ？」                                                     |
| ② うごかす          | 「ひだりの ブロックを みぎに ひっぱってきて、くっつけてみよう」「ひだりの え が、ブロックの とおりに うごくよ」 |
| 「うみに はなす」前 | 「はなすと、もう なおせないよ。いい？」                                                                         |
| ③ うみへ            | 「あの 大きな 画面を みてて！ うえから おりてきて、ひかってるのが きみの なかまだよ」                           |
| 終わったあと        | クリアカードを渡して「たいけん ありがとう！」                                                                   |

## 4. 案内で知っておくこと

### ① かく

- **頭が右を向くように描いてもらいます。** 紙の右下に「すすむ むき →」と出ています。大画面では、左へ泳ぐときは絵を左右反転するので、右向きに描くと頭が進む向きにそろいます（ぬりえのイニャーも右向きです）
- 絵の中に字を書くと、左へ泳ぐ間は鏡文字になります
- ぬりつぶしは、線でかこんだところだけ塗れます。すき間があると「ここは ぬれないよ」と出ます
- 白っぽい色は大画面で見えなくなるので選べません
- 何もかいていないと「つぎへ」で先へ進めません
- おえかきとぬりえは、かく画面の上でも切り替えられます。切り替えると、かいた絵は消えます

### イニャーのぬりえ

デザイン部と権利者に確認済みで、ふつうのぬりえとして楽しむぶんには問題ありません。

- どんな色でぬっても止めません（全身ピンク、はみ出している、なども大丈夫）
- 顔をうんちに描きかえるなど、人に見せられない絵は「つぎへ」の前にやさしく声をかけて直してもらいます
- 大画面に出てしまったあとに気づいたら、保守に連絡してください

### ② うごかす

- ブロックを置くまでは、手がブロックを運ぶ見本が出ます。わからなそうなら、見本を指さして教えてください
- ブロックを右へドラッグして上下にくっつけると、上から順に動きます。消すときは右下のゴミ箱へドラッグします
- 「うごく」ブロックは 1 つで、▼ を押すと動き（ジャンプする・くるっとまわる など）を選べます
- ブロックは **10 個まで**（くりかえしや「もし」の中も数えます）。くりかえしや「もし」の中に入れ子にできるのは 1 段までです
- 「もし なかまが ちかくに いる」は近くにほかの絵がいるとき、「もし はしに いる」は画面の左右のはしにいるときだけ動きます。「もし くじが あたる（4かいに 1かい）」などは、その割合で当たったときだけ動きます
- 「いう」で「じぶんで かく…」を選ぶと、25 文字までセリフを打てます

## 5. 混雑しているとき

- 待っている人には、大画面を見ながら待ってもらいます
- 時間がかかっている人には声をかけます。① かく が 5 分を超えたら「そろそろ『つぎへ』に すすもうか」、② うごかす が 5 分を超えたら「そろそろ うみに はなそうか」
- 【ほかに決めること：整理券、1 人あたりの時間を短くする、など】

## 6. よくある質問

| 質問                       | 答え                                                                                                                 |
| :------------------------- | :------------------------------------------------------------------------------------------------------------------- |
| 描き直したい・前に戻りたい | 「つぎへ」の前なら「ひとつ もどす」「ぜんぶ けす」で直せます。そのあとは左上の「さいしょから」で最初からやり直します |

## 7. 困ったとき

### 当番で対応できること

| 起きたこと                                                    | 対応                                                                     |
| :------------------------------------------------------------ | :----------------------------------------------------------------------- |
| 「まだ おくって いるよ」と出た                                | 少し待ってから「もういちど はなす」を押してもらう                        |
| 「うまく おくれなかったよ」「うまく おくれたか わからないよ」 | 「もういちど はなす」を押してもらう。同じ絵が 2 匹になることはありません |
| 参加者が途中でいなくなった                                    | 左上の「さいしょから」→「やりなおす」でホームに戻す                      |
| 大画面に「サーバーとの接続が切れました。再接続しています…」   | 自動でつながり直すので、しばらく待つ                                     |

### 保守を呼ぶとき

次のときは、自分で直そうとせずに保守を呼んでください。

- 「この パソコンは じゅんび ちゅうだよ」と出た
- 「もういちど はなす」を何回押しても送れない
- 大画面の「再接続しています…」が 1 分以上消えない
- 送れたのに、大画面に絵が出てこない
- 人に見せられない絵が大画面に出てしまった（保守が「大画面から作品を消す」の手順で消す）
- 画面が動かない、真っ白になった、知らない画面が出た
- そのほか、わからないこと

**PC を再起動したり、ブラウザを閉じたりしないでください。** 放流の設定がやり直しになることがあります。

保守の名前と連絡先：【名前・連絡方法】

### 大画面から作品を消す（保守）

人に見せられない絵が大画面に出てしまったときに、その作品だけを消す手順です。Cloudflare に実行委員会のアカウントでログインできる人が行います。

1. いつごろ放流された作品かを確かめる（だいたいの時刻でよい）
2. Cloudflare のダッシュボードを開き、「R2 オブジェクトストレージ」→ バケット `2026-programming-experience` →`creatures/` フォルダを開く
3. 作品は 1 匹につき 1 つのファイルで、名前は「放流した時刻-ランダムな文字.png」です。名前の順（＝放流した順）に並ぶので、新しい作品ほど後ろのページにあります。「変更日時」の列を見て、1 の時刻のファイルを探す
4. ファイルを開いて、消したい絵かどうかを確かめる
5. **そのファイル 1 つだけ**を選んで削除する。`assets/`（大画面の背景）や、ほかの作品は消さない
6. 大画面の PC で F5 を押して読み込み直す（開いたままだと、消した作品が泳ぎ続けます）。大画面にはキオスクの制限がないので、F5 で読み込み直せます

- 消した分は、その前に出ていった作品が 1 匹戻ってきて、15 匹のままになります
- 本番前に試した作品をまとめて消すときは、`creatures/` の中身を全部消します（`assets/` は残す）

## 8. クリアカード

- 「うみに はなす」で放流して「うみに はなしたよ！」の画面が出たら、その場で渡します
- 渡すのは、その PC のまわりにいる見回りです
